ما هو خادم ArcGIS Pro MCP؟

MCP (Model Context Protocol) هو بروتوكول قياسي يسمح لوكلاء الذكاء الاصطناعي باستخدام البرامج الموجودة على جهازك. هذا البرنامج يجعل أي وكيل ذكاء اصطناعي، مثل Claude أو ChatGPT أو Gemini أو Codex، قادراً على التحكم في ArcGIS Pro مباشرة: فتح المشاريع، وإضافة البيانات، والتحليل المكاني، والترميز، والتسميات، والتعديل، وإنشاء الخرائط الإخراجية (Layouts) وتصديرها، وتشغيل أي أداة معالجة جغرافية، وتنفيذ أكواد ArcPy، بل والضغط على أي زر في واجهة البرنامج.

كل ما عليك هو أن تكتب طلبك بلغتك العادية، مثلاً:

أضف طبقة المحافظات، ولوّنها حسب عدد السكان، ثم أنشئ خريطة إخراجية فيها عنوان ومفتاح خريطة وصدّرها PDF.

كيف يعمل؟

وكيل الذكاء الاصطناعيClaude, ChatGPT, Gemini, Codex ...
→

→

الاتصال بين الخادم وArcGIS Pro محلي بالكامل على جهازك (Named Pipe)، ولا يمر عبر الإنترنت.

المتطلبات

العنصرالتفاصيل
نظام التشغيلWindows 10 أو Windows 11 (64 بت)
ArcGIS Proأي إصدار من 3.0 إلى 3.7، مع ترخيص فعّال
وكيل ذكاء اصطناعيواحد على الأقل: Claude Desktop، Claude Code، ChatGPT، Codex، Gemini CLI، Antigravity، Cursor، Windsurf، VS Code، Cline، LM Studio ... إلخ
مكتبات أو أدوات إضافيةلا يلزم أي شيء. لا Python ولا .NET ولا صلاحيات مسؤول (Administrator). الملف ArcGISProMCP-Setup.exe يحتوي على كل شيء.

التثبيت خطوة بخطوة

  1. أغلق ArcGIS Pro إن كان مفتوحاً.
  2. شغّل الملف ArcGISProMCP-Setup.exe بالنقر المزدوج.
    إذا ظهرت رسالة Windows SmartScreen فاضغط «More info» ثم «Run anyway».
  3. ستظهر نافذة البرنامج، وفيها: إصدار ArcGIS Pro المكتشف على جهازك، وقائمة بوكلاء الذكاء الاصطناعي الموجودين عندك، وتكون محددة تلقائياً.
  4. حدّد الوكلاء الذين تريد ربطهم، أو اضغط Select all لتحديدهم جميعاً.
  5. اضغط الزر الأزرق Install / Update تثبيت وانتظر حتى يظهر في السجل السطر == Done ==.
  6. أعد تشغيل برامج الذكاء الاصطناعي (مثل Claude Desktop وCursor) حتى تتعرّف على الخادم الجديد.
ما الذي يحدث أثناء التثبيت؟ يُنسخ البرنامج إلى %LOCALAPPDATA%\Programs\ArcGISProMCP، وتُثبَّت إضافة ArcGIS Pro في مجلد الإضافات الخاص بك، وتُضاف إعدادات الخادم إلى ملفات إعداد كل وكيل اخترته (مع حفظ نسخة احتياطية منها)، ويُسجَّل البرنامج في قائمة «التطبيقات المثبتة» في Windows، ويُنشأ له اختصار في قائمة ابدأ.

التأكد من عمل الإضافة داخل ArcGIS Pro

  1. افتح ArcGIS Pro وافتح أي مشروع.
  2. ستجد في الشريط العلوي تبويباً جديداً اسمه AI / MCP.
  3. اضغط MCP Status، ويجب أن تظهر رسالة MCP Bridge is RUNNING.
  4. يمكنك أيضاً أن تفتح نافذة البرنامج من قائمة ابدأ وتضغط Test connection to Pro.
لم يظهر التبويب؟ من داخل ArcGIS Pro افتح: Project ← Add-In Manager ← Options، واختر Load all Add-Ins without restrictions، ثم أعد تشغيل ArcGIS Pro.

ربط وكلاء الذكاء الاصطناعي

الوكلاء التالية يربطها المثبّت تلقائياً، وكل ما عليك هو إعادة تشغيل الوكيل بعد التثبيت:

الوكيلملاحظات
Claude Desktopبعد إعادة التشغيل يظهر arcgis-pro ضمن أيقونة الأدوات (🔨) في خانة الكتابة.
Claude Codeيُضاف على مستوى المستخدم. اكتب /mcp للتأكد من الاتصال.
OpenAI Codex (CLI / IDE / App)يُضاف إلى ~/.codex/config.toml.
Gemini CLIيُضاف إلى ~/.gemini/settings.json. اكتب /mcp للتأكد.
Google Antigravityيُضاف إلى mcp_config.json. يظهر في قائمة MCP Servers.
Cursor / Windsurf / Kiro / Traeيظهر في إعدادات MCP، وتأكد أن المؤشر بجوار الخادم أخضر.
VS Code (Copilot) / Cline / Roo Codeيظهر في قائمة MCP Servers داخل الإضافة.
Qwen Code / LM Studio / opencode / Amazon Qيُضاف تلقائياً إذا كان الوكيل مثبتاً.
في أول مرة سيطلب منك الوكيل الموافقة على استخدام أدوات arcgis-pro، فاضغط «Allow» أو «سماح».

ربط ChatGPT (وضع HTTP)

ChatGPT يعمل من خوادم OpenAI على الإنترنت، لذلك يحتاج إلى رابط HTTPS عام يصل إلى جهازك. نوفّر هذا الرابط بخطوتين:

  1. افتح نافذة البرنامج من قائمة ابدأ (ArcGIS Pro MCP Server)، واترك المنفذ 3939، واضغط Start HTTP server. سيظهر في السجل رابط يحتوي على رمز سري (Token). اترك النافذة مفتوحة.
  2. شغّل نفقاً (Tunnel) آمناً في نافذة أوامر، باستخدام أحد البرنامجين المجانيين: 
    cloudflared tunnel --url http://localhost:3939
ngrok http 3939
    ستحصل على رابط مثل https://xxxx.trycloudflare.com.
  3. في ChatGPT افتح: Settings ← Apps & Connectors ← Advanced ← Developer mode وفعّله.
  4. اضغط Create لإضافة Connector جديد، وضع الرابط بهذا الشكل: 
    https://xxxx.trycloudflare.com/mcp/الرمز-السري
    واختر Authentication: No authentication، لأن الرمز السري موجود بالفعل داخل الرابط.
  5. في المحادثة اختر الـ Connector من قائمة الأدوات وابدأ بكتابة طلباتك.
تنبيه أمني: أي شخص يعرف الرابط كاملاً مع الرمز يمكنه التحكم في ArcGIS Pro على جهازك. لا تنشر الرابط، وأوقف الخادم والنفق عندما تنتهي.

ربط DeepSeek وأي وكيل آخر

أي برنامج يدعم MCP يمكن ربطه، مثل Cherry Studio وChatbox وContinue وZed وGoose، أو أي برنامج يستخدم نماذج DeepSeek:

  1. افتح نافذة البرنامج واضغط Copy JSON config، وسيُنسخ الإعداد إلى الحافظة.
  2. الصقه في إعدادات MCP داخل الوكيل. شكل الإعداد: 
    {
  "mcpServers": {
    "arcgis-pro": {
      "command": "C:\\Users\\USER\\AppData\\Local\\Programs\\ArcGISProMCP\\ArcGISProMCP.exe",
      "args": ["--stdio"]
    }
  }
}
  3. إذا كان الوكيل يطلب رابطاً بدلاً من أمر تشغيل، فاستخدم وضع HTTP: http://127.0.0.1:3939/mcp/الرمز.
لاستخدام DeepSeek مع أدوات كاملة يمكنك ربط نموذج DeepSeek بأحد الوكلاء المدعومين، مثل Cline أو Roo Code أو Cherry Studio أو LM Studio، ثم ربط هذا الوكيل بالخادم كما سبق.

قائمة الأدوات المتاحة للوكيل

الخادم يوفّر 50 أداة. أهم أربع منها تعطي الوكيل تحكماً كاملاً في البرنامج:

الأداةالوظيفة
run_geoprocessingتشغيل أي أداة من أدوات المعالجة الجغرافية (أكثر من 1500 أداة): Analysis وData Management وSpatial Analyst وNetwork وغيرها.
run_pythonتنفيذ كود ArcPy داخل ArcGIS Pro على المشروع المفتوح، مع الاحتفاظ بالمتغيرات بين الأوامر.
search_commands + execute_commandالبحث عن أي زر في الشريط العلوي (أكثر من 6000 أمر) والضغط عليه.
get_layer_cim / set_layer_cimتحكم كامل في الترميز والتسميات والنوافذ المنبثقة (Pop-ups) لأي طبقة.

حل المشكلات الشائعة

المشكلةالحل
الوكيل لا يرى أدوات arcgis-proأعد تشغيل الوكيل بالكامل (أغلقه من شريط المهام أيضاً). وتأكد في نافذة البرنامج أن الوكيل مكتوب بجواره configured ✔.
رسالة «ArcGIS Pro is not running»اطلب من الوكيل تشغيله («شغّل ArcGIS Pro») أو افتحه يدوياً.
رسالة «the MCP Bridge add-in is not loaded»من داخل Pro: Project ← Add-In Manager ← Options ← Load all Add-Ins without restrictions، ثم أعد تشغيل Pro. وإن لم ينجح ذلك، أعد التثبيت.
الأمر يستغرق وقتاً طويلاًأدوات التحليل الكبيرة قد تستغرق دقائق، والخادم يرسل إشارات تقدم للوكيل. إن انتهت المهلة فقد تكون العملية ما زالت تعمل داخل Pro.
Pro يعرض نافذة حوار (حفظ، تأكيد ...)أغلق النافذة يدوياً، لأن الوكيل لا يستطيع الضغط على نوافذ الحوار.
أكثر من نسخة Pro مفتوحةاطلب من الوكيل: «اعرض نسخ ArcGIS Pro المفتوحة واختر النسخة رقم ...».
ChatGPT لا يتصلتأكد أن خادم HTTP والنفق يعملان، وأن الرابط ينتهي بـ /mcp/الرمز، وأن الرابط يبدأ بـ https.

سجلات التشغيل موجودة في: %LOCALAPPDATA%\ArcGISProMCP\logs، ويمكنك فتحها من زر Open logs.

الأمان والخصوصية

  • كل الاتصالات تتم محلياً على جهازك، ولا تُرسل بياناتك إلى أي مكان إلا إلى وكيل الذكاء الاصطناعي الذي اخترته أنت.
  • وضع HTTP يعمل افتراضياً على 127.0.0.1 فقط، وفتحه للشبكة يتطلب رمزاً سرياً.
  • الوكيل يستطيع تعديل البيانات وحذفها. راجع طلباتك، واحتفظ بنسخة احتياطية من بياناتك المهمة.
  • قبل أي تعديل على ملفات إعداد الوكلاء يحفظ المثبّت نسخة احتياطية منها باسم *.bak-arcgispro-mcp.

إلغاء التثبيت

اختر إحدى الطرق التالية:

  • من Settings ← Apps ← Installed apps اختر ArcGIS Pro MCP Server ثم Uninstall.
  • أو افتح نافذة البرنامج واضغط Uninstall إزالة.

تُزال الإضافة من ArcGIS Pro، وتُحذف إعدادات الخادم من كل الوكلاء، ويُحذف البرنامج نفسه.

ArcGIS هي علامة تجارية مسجلة لشركة Esri. هذا البرنامج أداة مستقلة وليس منتجاً رسمياً من Esri.
